# Nini World Championship · estadísticas

Web de estadísticas de la liga: **https://niniworldchampionship.github.io**

Se reconstruye sola cada noche, justo después de cerrar el juego del día, y otra vez cuando el pipeline
oficial publica los resultados de la mañana. Este repo solo tiene el workflow que la construye
(`.github/workflows/web.yml`); el código está en un repo privado.
